# Julián Fonseca — Servicios Web e Inteligencia Artificial

Página profesional de servicios: la propia página es la demostración. El hero corre un **campo neuronal escrito en WGSL sobre WebGPU** en tiempo real, que reacciona al puntero.

## Servicios

- Agentes de IA para tareas específicas y de uso general
- RAG y embeddings sobre documentos propios
- Integraciones API y Model Context Protocol (MCP)
- Juicio calibrado con Jev / TypeSafe
- Experiencias y cómputo WebGPU

## Stack

JavaScript · TypeScript · Node.js · LLMs · Embeddings · RAG · APIs REST/GraphQL · MCP · WebGPU (WGSL)

## Verla

Publicada con GitHub Pages: https://fonck95.github.io/julianfonseca/

Un solo archivo (`index.html`), sin dependencias: HTML + CSS + el shader WGSL embebido. Si el navegador no soporta WebGPU, hay un degradado de respaldo.
